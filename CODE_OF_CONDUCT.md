# Code of Conduct

Contributors to this repository are expected to follow the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/):
be respectful, assume good intent, give constructive feedback, and keep discussions focused on the work.

Report unacceptable behaviour to the project maintainers at TTNS. All reports are reviewed and handled confidentially.
